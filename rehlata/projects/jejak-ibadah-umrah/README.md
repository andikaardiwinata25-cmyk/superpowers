# Jejak Ibadah — Umrah berkali-kali

Video Remotion 1080x1920, 30 fps, 82,9 dtk. Media (video ustadz, b-roll, SFX, gambar)
tidak disimpan di repo; ambil dari Drive "CLAUDE EDITOR" ke folder `public/`
(`main.mp4`, `voice.wav`, `broll/*.mp4`, `sfx/*.wav`, `img/*.png`, `trans/*.mp4`, font TTF).

Render: `npm install && node stills.mjs render out/full.mp4`

Hadits: «الْعُمْرَةُ إِلَى الْعُمْرَةِ كَفَّارَةٌ لِمَا بَيْنَهُمَا» — HR. al-Bukhari no. 1773 & Muslim no. 1349 (Abu Hurairah).
